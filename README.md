# Dota Insights

AI-accessible analytics for Dota 2. A public MCP server you connect to Claude Code, Claude Desktop, Cursor
and other MCP clients, so your assistant can answer questions about heroes, items, economy, matches,
players and the pro scene from real match data.

Every result comes in one envelope: `status` (`ok`, `insufficient_data` or `error`), the result, the
sample size, filters, period, metric definitions, 95% confidence intervals, caveats and data sources.
When there are too few matches, `insufficient_data` carries a `hint` on how to widen the filters. When a
data source fails (rate limit, outage, missing STRATZ token, timeout), `error` says what happened and the
`hint` says whether and when to retry.

## Connect

The server speaks MCP over Streamable HTTP at `http://<host>:<port>/mcp` (default
`http://127.0.0.1:8000/mcp`). Start it locally with `uv run dota-insights` (see [Development](#development)).

**Claude Code**

```bash
claude mcp add --transport http dota-insights http://127.0.0.1:8000/mcp
```

Add `--scope user` to use it in every project. Check it with `claude mcp list`, or `/mcp` inside a
session.

**Claude Desktop**

For a server reachable over HTTPS, open Settings → Connectors → Add custom connector and enter its `/mcp`
URL. For a server on your own machine, bridge it with `mcp-remote` in `claude_desktop_config.json`
(Settings → Developer → Edit Config), then restart Claude Desktop:

```json
{
  "mcpServers": {
    "dota-insights": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "http://127.0.0.1:8000/mcp"]
    }
  }
}
```

Other clients (Cursor, VS Code, ...) take the same URL as a "streamable HTTP" MCP server.

## Data limitations

- **OpenDota free tier.** 60 requests a minute and 3,000 a day, shared by every user of a server. Results
  are cached (hero and item aggregates for hours, finished matches for a week), but a cold question that
  fans out over many heroes or matches can hit the limit; the tool then answers `error` with a retry hint.
- **Few parsed matches.** Only about 8% of public matches are replay-parsed on OpenDota. Timelines,
  teamfights, wards, lane outcomes, purchase logs and per-minute farm exist only for parsed matches, so
  those tools say when a match is unparsed and aggregates over parsed data rest on smaller samples.
- **No separate Immortal bracket in OpenDota.** OpenDota aggregates fold Immortal into Divine (bracket 8
  is empty). Rank-filtered hero, item and build statistics come from STRATZ, which does separate
  Immortal; OpenDota-only tools treat `divine+` as the top bracket.
- **STRATZ.** STRATZ data needs a server-side API token (`DOTA_INSIGHTS_STRATZ_API_TOKEN`). Without it,
  STRATZ-backed tools return an `error` saying so and OpenDota-backed tools keep working. Results built
  from STRATZ list `"stratz"` in `source` and must credit it: data from [STRATZ](https://stratz.com).
- **Correlation, not causation.** Item, build and timing win rates describe the games where players made
  that choice; they do not prove the choice caused the win. Tools say so in `caveats`.
- **Public profiles only.** Player tools need an exposed match history; private profiles return nothing.
- **Pro data** covers league matches OpenDota tracks; small tournaments and very recent games may be
  missing.

Data from [OpenDota](https://www.opendota.com) and [STRATZ](https://stratz.com). Dota 2 is a registered

## Development

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/).

```bash
uv sync
cp .env.example .env
uv run dota-insights          # serves MCP over Streamable HTTP at http://127.0.0.1:8000/mcp
uv run pytest
uv run ruff check . && uv run ruff format --check .
```

Tool conventions are in [docs/architecture/tools.md](docs/architecture/tools.md). Changes are listed in
[CHANGELOG.md](CHANGELOG.md).

## Layout

```
src/dota_insights/
  mcp/         MCP server, tools, prompts, result envelope and error handling
  sources/     OpenDota, STRATZ and Steam Web API clients
  collector/   scheduled data collection jobs
  db/          PostgreSQL schema and access
  analytics/   metric calculations and sample-size checks
  telegram/    insight generator and channel publishing
  config.py    settings from DOTA_INSIGHTS_* environment variables
scripts/       reference data refresh, README tool table generator
```
